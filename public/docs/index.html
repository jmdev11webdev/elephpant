elePHPant Repository Guide

Technical reference for the jmdev11webdev/elephpant repository—covering architecture boundaries, folder layout, local WSL2 setup, sandbox commands, and contributor checks.

Backend

Laravel 13 (PHP 8.3+), Fortify authentication (email verification disabled), Wayfinder typed routes, SQLite / PostgreSQL.

Frontend Shell

Vue 3 + TypeScript + Inertia.js v3 + Tailwind CSS v4 + Vite+, hosting /dashboard, /play, and /resources.

Game & IDE

Phaser 3.90.0 (Tsugumi) 16-bit engine decoupled via a typed event bus, paired with an embedded Monaco Editor workspace.

Repository Structure

Strict separation of concerns keeps Laravel, Vue, Phaser, and challenge content independent: 

elephpant/
├── app/
│   ├── Console/Commands/       # php artisan challenges:sync
│   ├── Contracts/              # ChallengeRunnerInterface.php
│   ├── Http/Controllers/       # Dashboard, Resource, Challenge, Title controllers
│   ├── Models/                 # User, Challenge, ChallengeSubmission, progression models
│   └── Services/               # PlayerProgressOverview, ProgressionService, Sandbox drivers
├── challenges/                 # Decoupled challenge bundles (<discipline>/<slug>/)
├── config/
│   ├── fortify.php             # Auth & local WebAuthn passkeys config
│   ├── resources.php           # Static curated PHP/Laravel resource catalog
│   └── sandbox.php             # Piston / fake sandbox driver configuration
├── public/
│   ├── assets/                 # 16×16 pixel-art tilesets, sprites, and Tiled JSON maps
│   └── docs/                   # Standalone HTML/CSS/JS repository documentation
├── resources/js/
│   ├── components/game/        # PhaserGame.vue, DialogueBox.vue
│   ├── components/ide/         # ChallengeCenterModal.vue, MonacoCodeEditor.vue
│   ├── game/                   # config.ts, events.ts, scenes/ (Phaser-only layer)
│   └── pages/                  # Welcome.vue, Dashboard.vue, Play.vue, Resources.vue
├── tests/                      # Pest feature & unit tests
└── docker-compose.sandbox.yml  # Isolated WSL2 Piston Docker sandbox

Local WSL2 (Debian) Setup

Clone the repository and bootstrap PHP + Node dependencies: 

git clone https://github.com/jmdev11webdev/elephpant.git
cd elephpant
composer setup

Run the Laravel server and Vite dev server together:

composer run dev

Local Passkeys Note: Visit http://localhost:8000 (instead of 127.0.0.1) so browser WebAuthn allows local passkey registration and login.

Sandbox & Challenge Sync

Sync version-controlled challenge bundles into SQLite or PostgreSQL: 

php artisan migrate
php artisan challenges:sync

Pull and verify the hardened ephemeral PHP 8.5.13 Docker sandbox image (network disabled, read-only root, non-root UID 65534, cgroup v2 limits): 

docker compose -f docker-compose.sandbox.yml pull
docker compose -f docker-compose.sandbox.yml run --rm php-sandbox php -v

Quality, Lint & Test Commands

Run these checks before opening a pull request or tagging a milestone: 

vendor/bin/pint --dirty --format agent
npm run check
npm run types:check
npm run build
composer types:check
php artisan test --compact

Contributing Workflow

  • Fork or branch from main on github.com/jmdev11webdev/elephpant.
  • Keep Phaser scenes decoupled from Vue, Inertia, and Monaco—use resources/js/game/events.ts.
  • Store new challenges as standalone bundles in challenges/<discipline>/<slug>/ with verified solution/ files and public + hidden tests.
  • Ensure all Pint, Larastan, TypeScript, Vite+ lint/build, and Pest checks pass before submitting a PR.
