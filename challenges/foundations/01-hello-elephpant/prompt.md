# Step 1: Hello, elePHPant!

> **Concept Reference: Standard Output (`echo`)**
> PHP scripts begin with the opening tag `<?php`. Use the `echo` language construct to write string output to stdout, and terminate every statement with a semicolon (`;`).
>
> ```php
> <?php
>
> echo "Welcome!";
> ```

## Requirements

1. Keep the `<?php` opening tag at the top of `Hello.php`.
2. Use `echo` to print the exact string `Hello, elePHPant!`.
3. Terminate the statement with a semicolon (`;`).
4. Match capitalization (`elePHPant`), punctuation, and spacing exactly.

## Example

```php
// Expected stdout output:
Hello, elePHPant!
```
